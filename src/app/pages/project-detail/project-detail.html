Key decisions

Why I built it this way.

ECS Fargate

No EC2 host management. The project stays focused on containers, networking and application infrastructure.

RDS + S3

Persistent data is separated from disposable ECS tasks, so redeployments do not destroy application state.

Terraform

The environment can be recreated and reviewed instead of depending on manual AWS console configuration.

MAIN CHALLENGE

Containers can disappear. The data cannot.

ECS tasks are replaceable, so application state could not live inside the container.

I separated persistence from compute using RDS PostgreSQL and S3. This allowed ECS tasks to restart or be replaced without losing application data.

RESULT

Reproducible and recoverable infrastructure.

  • Terraform-managed AWS infrastructure
  • Persistent database and file storage
  • Secrets kept outside source code
  • CloudWatch logging and monitoring
  • Backup and restore behavior tested
